# SmartRent Manager by EFTNIX

Ready-to-demo responsive rental management web app.

Features: dashboard, property records, tenant and lease records, rent payment recording, printable receipts, expense tracking, financial summary, CSV export, JSON backup/restore, responsive layout.

## Deploy to GitHub Pages
1. Create a new repository, e.g. `smartrent-manager`.
2. Upload `index.html` and `README.md` to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Open the Pages URL provided by GitHub.

## Important
This is a functional **single-browser demo / pilot**, not production multi-user SaaS. Data is stored in browser localStorage on that device only. No cloud database, user authentication, tenant login, payment gateway, automated messages, or server-side backup is included. Do not store sensitive identity documents or use it as the sole financial record for a paying customer. Before commercial deployment, implement secure backend/database, authentication, role-based access, tenant isolation, server-side validation, audit logs, backups, privacy policy and applicable local legal requirements.
